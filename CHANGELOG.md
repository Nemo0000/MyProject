# Changelog

## [0.2.0] - 2026-08-14

- Added a documented `getData` API for reading selected names and administrative codes.
- Fixed jQuery plugin method return values for getter methods such as `getVal` and `getData`.
- Added keyboard open/close behavior and ARIA state updates for the generated picker control.
- Reworked the demo with English and Simplified Chinese instructions, responsive layout, and API output.
- Added bilingual README documentation and MIT licensing.

## [1.0.2-era baseline] - 2018-01-12

- Original Bootstrap-based province/city/district picker demo published to GitHub.
